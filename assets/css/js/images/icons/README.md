Habit Tracker 2

A modern and responsive Habit Tracker web application built using HTML, CSS, and JavaScript.

Features

- Add new habits
- Delete habits
- Mark habits as completed
- Daily progress tracking
- Notes section with auto save
- Local Storage support
- Smooth sidebar navigation
- Responsive design
- Dark Theme

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open "index.html" in your browser.
